================================================================================
EXTRAS-README: CodeBrix.Cryptography
Samples, tools and other content in this repository that is not part of a NuGet
package
================================================================================

This repository ships no sample applications, demo apps or tools. The only
content outside the packaged library is the test project and its fixture data.
Everything described below is repository content; none of it is packed into the
CodeBrix.Cryptography.MitLicenseForever package.


tests/CodeBrix.Cryptography.Tests/
==================================

The test project — a port of the upstream BouncyCastle.NET NUnit suite to
xUnit.v3, with SilverAssertions available. Its folder tree mirrors the library's
namespaces (Asn1/, Bcpg/, Cms/, Crypto/, Math/, Ocsp/, OpenSsl/, Pkcs/, Pkix/,
Pqc/, Security/, Tests/, Tls/, Tsp/, Utilities/, X509/, Cert/, Cmp/, Crmf/,
Mozilla/).

For consumers of the package, this suite is the richest set of worked examples
available — see the "WORKING EXAMPLES ON GITHUB" section of AGENT-README.txt for
a feature-to-test-file map. For maintainers, see MAINTAINER-README.txt for how
to run it and what is gated.

    dotnet test CodeBrix.Cryptography.slnx


tests/CodeBrix.Cryptography.Tests/data/
=======================================

303 fixture files inherited from the upstream repository's own
crypto/test/data (MIT, like the rest of that repository). They are compiled
into the test assembly as embedded resources under the logical prefix
"CodeBrix.Cryptography.data." — which is why the test project sets
<RootNamespace>CodeBrix.Cryptography</RootNamespace>. SimpleTest.GetTestData and
SimpleTest.GetTestDataAsStream read them, so they are always present and never
depend on the working directory.

The csproj excludes **\README.txt from the embedded set.


tests/CodeBrix.Cryptography.Tests/TestDataGeneration/
=====================================================

The fixture generators that produce the self-authored half of test-data/:
Asn1FixtureGenerator, CmpFixtureGenerator, SampleCertificateGenerator,
TlsCredentialGenerator and the shared TestDataPaths helper.

They are skipped unless CODEBRIX_CRYPTOGRAPHY_REGENERATE_TEST_DATA=1 is set, so
they never run in a normal test pass or in CI:

    CODEBRIX_CRYPTOGRAPHY_REGENERATE_TEST_DATA=1 dotnet test \
        --filter "FullyQualifiedName~TestDataGeneration"


test-data/
==========

1,762 files, about 18 MB, copied next to the test assembly at build time by a
<Content Include="..\..\test-data\**\*.*"> item group in the test csproj.
SimpleTest.FindTestResource resolves them from AppContext.BaseDirectory, so the
suite never reaches outside the repository. This directory is the
repository-local replacement for upstream's external bc-test-data clone.

Three origins, all recorded in THIRD-PARTY-NOTICES.txt:

  test-data/tls/credentials/     180 files
  test-data/pkix/                 10 files (cert/ and cms/ — ML-KEM, ML-DSA and
                                  SLH-DSA sample credentials and CMS SignedData
                                  samples)
  test-data/asn1/                  2 files (nested_seq.der, nested_seq_indef.ber
                                  — deeply-nested ASN.1 stress fixtures)
  test-data/cmp/                   1 file  (sample_cr.der)
      Together, 193 files generated by this library itself. Regenerate them with
      the TestDataGeneration filter above.

  test-data/crypto/ascon/         11 files
      Ascon known-answer test vectors taken from the Ascon team's own reference
      implementation repository, https://github.com/ascon/ascon-c, under the
      CC0 1.0 Universal public domain dedication. THIRD-PARTY-NOTICES.txt entry
      7 lists the per-file upstream provenance.

  test-data/PKITS/             1,558 files
      The NIST PKITS (Public Key Interoperability Test Suite) 2011 archive,
      extracted verbatim: certs/ (405), pkcs12/ (405), certpairs/ (348),
      smime/ (224), crls/ (173), plus pkits.ldif, pkits.schema and ReadMe.txt.
      No file has been modified. The test suite reads only certs/ and crls/; the
      rest is retained so the vendored copy is the archive as published rather
      than a subset. This is US government public information — see
      THIRD-PARTY-NOTICES.txt entry 8 for the source URL, edition and archive
      hash.


NOT IN THIS REPOSITORY — bc-test-data
=====================================

Upstream keeps a further set of fixtures (post-quantum known-answer vectors from
the individual NIST PQC submission packages, the LMS/HSS vectors and one
Grain-128AEAD vector) in https://github.com/bcgit/bc-test-data.git — roughly
4.6 GB with no licence file, so it cannot be redistributed inside an
MIT-licensed repository. The tests that read it are skipped by default and can
be enabled by cloning that repository as a SIBLING of this one and setting
CODEBRIX_CRYPTOGRAPHY_USE_BC_TEST_DATA=1. See MAINTAINER-README.txt for the
details.
